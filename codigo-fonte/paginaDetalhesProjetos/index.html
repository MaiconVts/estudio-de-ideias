Sistema de Gestão de Bibliotecas

Equipe de Desenvolvimento

Ana Clara Souza
Lucas Mendes
João Pedro Ferreira

Resumo

Este projeto consiste no desenvolvimento de um sistema web voltado para a gestão de bibliotecas acadêmicas. A plataforma permite o controle de empréstimos, devoluções, reservas e gestão de acervo, utilizando a tecnologia Django no backend e ReactJS no frontend.

Ano de Publicação: 2025

Tecnologias Utilizadas: Django, ReactJS, PostgreSQL, HTML5, CSS3

Disciplina Associada: Desenvolvimento Web Full Stack

Categoria do Projeto: Sistema Acadêmico
